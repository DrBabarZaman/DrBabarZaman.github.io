The page now has a full-course folder panel and individual Lecture materials, Lab materials and Data materials cards. Category filters and expandable descriptions work locally; no Google Drive link has been supplied yet. The placeholders are labelled Coming soon and do not point to a fabricated folder.

Advanced Linear Algebra/

When ready, share the master folder link and, optionally, each subfolder's link. View-only Google Drive access is appropriate if students should read/download but not change materials. Keep access restricted to your intended audience; anyone-with-link access is optional, not automatically enabled by this website.

Edit advanced-linear-algebra-links.json with HTTPS Google Drive links, then run python3 update_course_links.py from this folder. The script validates Google URL hosts and replaces the placeholders with links that open in new tabs. Blank links remain pending. It updates only this course page; other course pages are unchanged. It does not create, upload or change Google Drive folders or sharing permissions.

The source script and link configuration are outside website/ and are not intended for public upload. After setting links, regenerate the upload ZIP from website/ or ask for it to be refreshed.

The live website has not been updated. The course hub's HTML, internal links, new assets and filter structure were checked; visual browser testing was unavailable in this session.
