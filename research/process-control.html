Research / Theme

Statistical process control

Detecting changes in process location and dispersion.

Focus

My doctoral thesis focused on mixed and adaptive memory control charts. My publication record includes methods applied to manufacturing processes, semiconductor wafers and wind turbines.

  • Mixed and adaptive memory control charts
  • CUSUM and EWMA methods
  • Robust score functions and generalized likelihood ratio tests
  • Multivariate monitoring and principal component methods

Examples from the CV

  • Mixed cumulative sum-exponentially weighted moving average control charts: An efficient way of monitoring process location (2015).
  • An improved process monitoring by mixed multivariate memory control charts: An application in wind turbine field (2020).
  • Adaptive CUSUM control charts for efficient monitoring of process dispersion (2022).
